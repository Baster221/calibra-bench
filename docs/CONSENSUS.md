# Bind the complete semantic outcome vector

After reference reveal, deterministic code freezes the exact questions and document. The leader independently derives every answer. Each validator repeats the substantive interpretation from those inputs and compares the complete canonical vector.

YES means the document supports the assertion; NO means it supports its negation; UNKNOWN means neither, ambiguity, inconsistency or an unavailable external fact. Absence is not automatically NO. Questions explicitly asking whether text contains a statement are interpreted as textual-presence questions.

Negation, qualifiers, exceptions, actors, quantities and times matter. A self-asserted certification is not independent verification. Embedded evaluator commands are untrusted data.

The parser requires every question ID exactly once, rejects Boolean IDs and extra fields, and canonicalizes row order. The canonical leader output must be a list of exactly the expected enum values. There is no confidence score or tolerance. UNKNOWN columns must also match because they determine the common denominator used for scoring.

Malformed/model-error leader results and validator exceptions disagree. No scoring write occurs until a valid consensus vector returns. All-UNKNOWN yields a visible void round, not a fabricated zero-error winner.

## Verification layers

1. Commitment checks bind actual content and timing independently of model outputs.
2. Validator tests explicitly execute captured validators with changed answers, reordered rows, malformed leaders and leader exceptions.
3. An independent Fraction-based reference checks all 27 outcome vectors and a probability grid.
4. State tests enforce phase closure, exact deadlines, reference substitution rejection, roster restrictions, missing reveals and display-rounding independence.
5. The live script uses real network model consensus. The public read-only verifier recomputes opened commitments, losses and ranks from fresh state.

Protocol finalization and execution success are checked separately. Actual votes are retained; majority agreement is not described as unanimity.
